# PropBuild Engineering Instructions

- Treat `tenant-management.html` as a supplied reference template; do not modify it unless the user explicitly authorizes that work.
- Do not create application frontend or backend code until the master specification explicitly calls for implementation.
- Keep product requirements and design decisions in `docs/MASTER_SPEC.md`; update it before implementing any changed requirement.
- Prefer small, testable changes and document verification performed with each implementation change.
- Do not commit credentials, tokens, personal data, or environment-specific secrets.
